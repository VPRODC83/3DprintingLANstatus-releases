# 3D Printing LAN Status — APKs

Este repositório contém apenas os instaladores (APK) do app **3D Printing LAN Status** para Android.
O código-fonte não fica aqui.

- Baixe o arquivo `3DPrintingLANStatus-<versão>.apk` na seção **Releases**.
- O app verifica este repositório para se atualizar sozinho (menu → Verificar atualização).
- `-migracao.apk` é só para quem tinha a instalação antiga e quer levar os dados para o app novo.
